# AI 大模型医疗 + 校园双场景问答系统 README
## 一、项目简介
### 1.1 项目背景与目标
本项目是《互联网应用软件开发综合实训》课程设计成果，聚焦医疗科普与校园服务双场景，基于RAG（检索增强生成）+ Agent（智能体）+ Gradio 技术栈，构建合规、高效、精准的智能问答系统。
核心目标：
- 医疗场景：提供专业合规的药物信息、症状处理科普，严格规避疾病诊断 / 治疗建议
- 校园场景：解答图书馆、宿舍申请、医保报销等高频校园咨询
- 技术落地：验证 Prompt 工程、RAG 检索、工具调用在垂直领域的应用可行性
### 1.2 核心技术亮点
- 双场景适配：医疗合规科普与校园事务咨询无缝切换，支持同义问句模糊匹配
- 轻量架构：无需 GPU，基于 Chroma 向量库实现本地知识库持久化，响应高效
- 合规强化：敏感词实时拦截、医疗回答强制追加上医提示，规避医疗风险
- 交互增强：支持多轮对话上下文关联、角色切换（患者 / 医生）、对话记录导出
- 易于扩展：知识库支持增量更新，新增场景无需修改核心逻辑

## 三、功能特性
### 3.1 医疗科普咨询模块
- 药物信息查询：支持 20 + 常用药物的适应症、禁忌、注意事项检索（如布洛芬、对乙酰氨基酚）
- 症状处理科普：提供儿童发烧、腹泻、跌倒应急等常见场景的处理建议
- 智能追问：信息不足时自动追问关键细节（如仅说 "头痛" 时追问持续时间、伴随症状）
- 敏感词拦截：识别 "确诊"" 癌症 " 等高危词汇，引导用户前往专科就诊
### 3.2 校园服务查询模块
- 支持场景：图书馆开放时间、宿舍申请流程、校园医保报销、成绩单打印
- 模糊匹配：通过同义扩展词典适配多样化问法（如 "图书馆几点开" 匹配 "图书馆开放时间"）
- 信息精准：直接引用校园知识库，确保回答权威性与时效性
### 3.3 交互增强功能
- 角色切换：患者模式（通俗语言）/ 医生模式（专业术语）
- 对话管理：支持清空历史、TXT 格式导出（含时间戳）
- 参考溯源：显示回答对应的知识库来源，增强信息可信度
- 多轮关联：自动关联历史对话意图（如先问 "儿童发烧" 再问 "用什么药" 可精准响应）
## 四、快速开始
### 4.1 环境准备
#### 4.1.1 依赖安装
# 1. 创建并激活conda环境（推荐）
conda create -n ai-med python=3.10
conda activate ai-med

# 2. 安装核心依赖（清华源加速）
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple zhipuai gradio chromadb pandas openpyxl
#### 4.1.2 智谱 API 密钥配置
- 访问 智谱 AI 开放平台 注册登录
- 进入控制台创建 API Key（格式为 {id}.{secret}）
- 配置方式：
        
  - 方式 1：直接修改 agent_tools.py，替换 client = ZhipuAI(api_key="你的API Key")
  - 方式 2：配置系统环境变量 zhipuai_api_key（推荐，避免密钥泄露）
### 4.2 项目启动
# 方式1：一键启动（自动检查依赖）
python run.py

# 方式2：直接启动前端
python app_gradio.py
启动成功后，自动打开浏览器访问 http://127.0.0.1:7860 即可使用
### 4.3 首次运行说明
- 首次启动时，系统自动初始化向量库，将医疗知识库导入 db_medical 目录
- 若修改 medical_knowledge.py 中的医疗数据，需删除 db_medical 文件夹后重启
- 校园知识库修改直接编辑 config.py 中的 CAMPUS_KNOWLEDGE 字典

- 角色选择：默认 "患者"（通俗语言），可切换 "医生"（专业术语）

  - 知识库查看：浏览医疗 / 校园知识库原始数据

## 七、知识库扩展指南
### 7.1 新增医疗知识
编辑 medical_knowledge.py，在 medical_raw_data 列表中追加结构化字典：
{
    "药物名称": "氯雷他定",
    "适应症": "缓解过敏性鼻炎、慢性荨麻疹症状",
    "禁忌": "对本品成分过敏者禁用"
}
- 删除 db_medical 文件夹
- 重启系统，自动导入新数据到向量库
### 7.2 新增校园场景
在 config.py 的 CAMPUS_KNOWLEDGE 中添加 "标准问题 - 答案"：
"选课咨询": "登录教务系统，进入「课程选择」模块，按学分要求选择课程并提交"
在 agent_tools.py 的 campus_synonyms 中添加同义关键词：
"选课咨询": ["怎么选课", "选课流程", "课程选择怎么操作"]
无需重启，即时生效

## 十一、常见问题 FAQ
Q1：启动失败提示 "API 调用失败"？
A1：1. 检查 API Key 是否正确配置；2. 确保网络通畅无防火墙拦截；3. 验证智谱 API 剩余 token 是否充足
Q2：修改知识库后新内容不生效？
A2：医疗知识库修改后需删除 db_medical 文件夹，重启系统重新导入；校园知识库修改即时生效
Q3：如何查看回答的参考来源？
A3：系统在 "参考资料 / 工具调用记录" 文本框中，会显示回答对应的知识库片段及相似度评分
Q4：对话记录导出后在哪里查看？
A4：导出的 TXT 文件会自动下载，文件名格式为 chat_record_2025XXXX_XXXXXX_.txt，包含完整对话轮次与时间戳
